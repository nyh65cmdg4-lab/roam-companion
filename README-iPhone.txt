Roam Companion - iPhone専用Webアプリ版

【重要】
これはiPhoneのSafariからホーム画面に追加して使うWebアプリ(PWA)です。
iPhone全体や他アプリのGPS位置情報を変更するものではありません。
地図タイル・場所検索にはインターネット接続が必要です。

【iPhoneだけでホーム画面に追加する方法】
1. このZIPを展開し、中のファイル一式をHTTPS対応のWebホスティングに公開します。
   例：GitHub Pages（SafariでGitHubにサインインし、リポジトリへファイルをアップロードしてPagesを有効化）。
2. 公開された https:// のURLをiPhoneのSafariで開きます。
3. Safariの共有ボタン →「ホーム画面に追加」→「追加」。
4. ホーム画面のRoamアイコンから起動します。

ZIPをiPhoneに保存しただけではホーム画面アプリとしてインストールできません。
PWAとして追加するにはHTTPSで公開されたURLが必要です。

【機能】
- 地図表示、場所検索
- 地図タップでルート地点追加
- ジョイスティックによるアプリ内座標移動
- 徒歩/自転車/車モード、速度調整
- ルート再生
- GPXインポート/エクスポート
- お気に入り、履歴（端末内保存）
- iPhoneの現在地取得（許可時）

【注意】
シミュレーション位置はRoam Companion内だけに反映されます。
